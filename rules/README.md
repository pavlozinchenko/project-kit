# rules

Reusable rule blocks pasted into the single `## Rules` list of a project's `AGENTS.md`. Pick as many as apply; a browser game takes both. Blocks are plain bullet lists without headings, so the result reads as one list. Remove duplicates by hand after pasting.

| Block | Use when the work involves |
|-------|----------------------------|
| `software.md` | code that runs: apps, scripts, generators, services |
| `content.md` | things people read or view: texts, pages, levels, images |

`scripts/adopt.sh <path> [software] [content]` appends the chosen blocks on first adoption. After that the project's `AGENTS.md` is edited by hand; the blocks here are a starting point, not a dependency.
